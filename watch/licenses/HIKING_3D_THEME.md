# Hiking 3D Theme

This note tracks the bundled `hiking-3d` Mapsforge render theme.

## What is bundled

- Theme name: `hiking-3d`
- Embedded app asset path: `app/src/main/assets/theme/hiking-3d/hiking-3d.xml`
- No external resources (no symbols, patterns or fonts): only colours and rules for OpenStreetMap tags.
